---
name: Canonical source integrity
description: Trust, authority, translation, ruleset, and invalidation rules for canonical private-library records.
---

Canonicalisation must copy one complete available source, never synthesize a rule by mixing fields. Official errata and later official revisions are hard selection constraints, not merely AI prompt hints. Machine translation is not canonical authority by itself and must receive an explicit comparison decision.

**Why:** A model can otherwise select a lower-authority source, and later source edits can silently keep an obsolete verified decision attached to changed content.

**How to apply:** Keep ruleset identity in grouping and provenance; quarantine explicit unsupported editions. Persist source-content fingerprints with the decision. Any change to canonical inputs must clear stale canonical linkage and provenance; unconfirmed edits remain blocked, while an explicitly human-verified correction may be trusted without reviving the old AI decision.
