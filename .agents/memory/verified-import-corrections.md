---
name: Verified import corrections
description: How human-reviewed OCR and translation corrections interact with later manual imports.
---

Human corrections must remain usable after the same source is imported again. A genuinely changed source must invalidate old corrections and return the content to review.

**Why:** Automatic imports must neither erase trusted work nor silently apply old corrections to new source material.

**How to apply:** Keep imported evidence distinct from reviewed results, and keep all lookup/search representations coherent when preserving a correction.
