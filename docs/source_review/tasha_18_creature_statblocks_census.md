# Tasha — all independent creature-statblock census

## Governing user rule (2026-10-15)
Every **self-contained creature stat block** counts as a monster/reference creature, whether playable as enemy, NPC, ally, magical summon, artificer/ranger companion, or a creature generated by a class feature. A **spell or feature without its own creature stat block** does not count. Record the source/role as metadata so an invoked companion remains distinguishable from a bestiary encounter. Preserve other existing references; do not delete a class feature merely because its creature now belongs in the monster index.

## Safe recovery rules
Source catalogue has active licensed `tce_2020_it` record for `Calderone-Omnicomprensivo-di-TASHA.pdf`, 194 pages; existing imported rows refer to suffixed `Calderone-Omnicomprensivo-di-TASHA_1787259976040.pdf`. That alias is part of historical provenance: do not rewrite it silently. For each candidate, source image verification, separate duplicates check by exact/normalized name, fail-closed numeric gates, guarded review history and green CI/Vercel are required before promoting it.

The present PR provides a protected, read-only source/duplication check for **Mimic Giovane** and negative regression tests, not live insertion of any Tasha creature. Additional candidates must receive their own source-specific review, especially level-dependent summons whose HP depends on caster/slot level; do not invent fixed HP for them. Class features and spells remain in their original categories as appropriate.
